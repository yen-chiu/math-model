## 内容

- **Python数学实验与建模课件**：课程使用的课件与示例
- **书中程序以及数据**：教材中的代码、数据与运行结果
- **课后习题初步解答**：个人整理的习题思路与代码
- **教材 PDF**：`Python数学实验与建模_(司守奎,_孙玺菁,2020）.pdf`

## 使用方式

1. 先看对应章节的课件，了解实验目的与数学背景。
2. 在 `书中程序以及数据/` 里找到示例代码，按需修改参数运行。
3. 做完习题后再对照 `课后习题初步解答/`，重点看思路而不是直接抄答案。
4. 需要完整教材时，下载根目录的 PDF 到本地阅读（文件较大，GitHub 网页端可能无法直接预览）。
